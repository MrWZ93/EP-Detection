# 1.0.0-preview.1

This is a local annotation preview, not a finished cloud collaboration deployment.

- Open local TDMS on demand without uploading or bulk-converting waveforms.
- Select and remember a local directory; browse/search original paths.
- Independent assessments, immutable revisions, durable local save and retryable account-scoped cloud queue.
- English Yes/No/Uncertain review flow, boundaries, region labels and zoom.
- Missing sample-rate metadata is explicit; unknown current calibration stays raw.
- Prepared administrator comparison, qualified EV/BV adjudication and Supabase RLS deployment scripts.

Mac Apple Silicon: bundled app built; executable self-test and local HTTP smoke test. Not Developer ID signed or notarized. Full GUI acceptance pending.

Windows: build workflow/instructions only; no tested Windows download.

Cloud: disabled until the coordinator deploys the reviewed schema, membership and login configuration and rebuilds with the public publishable key. No service-role secret is included. Preview-local reviews stay separate from later authenticated reviews.

Original data, prior tools, and prior annotation archives are not modified.
