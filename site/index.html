Start in three steps

  1. Prepare your data. Copy the study's original TDMS directory to your own computer. Keep filenames and relative folder structure intact. Keep your original backup. The application reads this folder; it does not move or rewrite recordings.
  2. Open EP Desktop. Extract the release archive and open the application. Keep its small launcher window open. Your browser opens a private local workspace. Choose your TDMS folder with the native folder picker. The folder is remembered.
  3. Sign in and enter your name. When the study's cloud deployment is enabled, use your approved study account and email code. Enter your reviewer name. In this preview, cloud login is disabled and local test reviews use a separate preview identity.

No database setup is required from reviewers. The coordinator configures the study service before a connected release is distributed.

Review a recording

  1. Browse the directory tree or search original paths. Select a file. The app hashes and opens that file on demand; large files may take longer.
  2. Inspect metadata, command voltage, current waveform, and experimental context. Names are clues, not scientific classifications. IV and capacitance recordings must not automatically be treated as EP.
  3. Confirm the acquisition profile only with evidence: command raw ÷ 10 once, NI column 0 command / column 1 current. Current remains raw when alpha/beta are unverified. Import the coordinator-provided dataset profile once for a confirmed batch. Its content hashes limit the sampling-rate setting to that batch and the UI shows the confirmation source. Unknown files without an interval use sample indices until verified.
  4. Write a review note. Choose No to save the exclusion and move on after local acknowledgment. Choose Uncertain when evidence is insufficient. Choose Yes to mark supported stages.
  5. Double-click the waveform to add boundaries. Drag boundaries to adjust them. Zoom using the range controls; you can add and move boundaries while zoomed. Label each region S1–S4 or Outside stages / QC. Use Undo if necessary.
  6. Choose Complete and next. Verify the separate local-save and cloud-sync statuses. New independent assessment creates another review without replacing earlier assessments.

Stage interpretation

S1: initial stable state. S2: isolated events and intervening silence. S3: sustained non-return before terminal stability. S4: terminal stable-high morphology candidate, not physical rupture confirmation. Stages may be absent; S4 must not be followed by S3. QC and withdrawal are independent. Explain uncertain post-QC continuation and genuine return evidence in the note.

Save, sync, and resume

Locally saved means the revision is durably stored on your computer. Cloud synced requires a server acknowledgment. A network failure keeps the revision in a retryable queue. Reopen the application with the same local user account and sign into the same study account to continue. Use Sync now to retry.

Use Export recovery file to make an additional annotation backup. It includes review metadata and notes, not waveform samples. Treat it as study data; do not attach it to a public issue. If a conflict is reported, export and contact the coordinator. Never delete the local data folder to resolve a conflict.

Questions and limits

Does this upload my 47 GB of TDMS files?

No. Waveforms are read locally. The sync payload contains review revisions, source hashes, relative paths, conditions, and progress. Administrator decisions may include attested boundary sample indices and voltage values, not waveform arrays.

Why is the time axis in samples?

The file has no sampling interval and does not match an imported confirmed dataset profile. Import the coordinator-provided profile for the study batch. Unknown new datasets still require verification; confirmed settings are never applied solely because a filename looks familiar.

Why is a file unavailable?

The file may be empty, changed, unreadable, or use an ambiguous channel mapping. The app explains the reason and retains other reviews. It does not silently substitute channels.

Will this change an older annotation tool?

No. This version uses its own application-data directory and loopback port 8780. Existing tools and annotations remain separate.

What if macOS blocks the app?

This preview is not notarized. Do not disable security protections or run commands that strip quarantine. Ask the coordinator for a signed and notarized release before broad distribution.

Can administrators compare reviewers?

The connected deployment enforces administrator membership on the server. Administrators can compare independent reviews and explicitly qualify EV/BV boundaries. Missing, censored, saturated, uncertain-calibration, stale-review, and duplicate-content cases are excluded from strict summaries. BV is not automatically assigned to S4 start.
